
# Blue Archive Character App

Aplikasi **Blue Archive Character** adalah aplikasi yang menampilkan informasi karakter-karakter dari game Blue Archive. Aplikasi ini dibangun menggunakan **Flutter** dan mengakses API untuk menampilkan data karakter.

## Fitur
- Daftar karakter Blue Archive.
- Detail karakter: foto, nama, sekolah, tanggal lahir, dan tipe damage.
- Tampilan responsif untuk perangkat mobile dan tablet.

## Teknologi yang Digunakan
- **Flutter** untuk aplikasi mobile.
- **Dart** sebagai bahasa pemrograman.
- **API Blue Archive** untuk mengambil data karakter.
- **Git** untuk kontrol versi.

## Persyaratan Sistem
- Flutter SDK versi 2.x atau lebih tinggi.
- Dart SDK versi 2.x atau lebih tinggi.
- Git untuk mengelola repositori.

### 1. Clone Repositori
Clone repositori ini dengan Git:

```

Masuk ke direktori proyek dan jalankan perintah:
```bash

```

Jalankan aplikasi di emulator atau perangkat fisik:

```
